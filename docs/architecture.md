# Architecture

All game logic runs on the server. The browser draws the state and sends orders. This keeps multiplayer over the internet possible without rework.

## Stack

| Layer           | Choice                                                                                         |
| --------------- | ---------------------------------------------------------------------------------------------- |
| Language        | TypeScript everywhere, so server and client share the types of state and protocol              |
| Workspace       | pnpm workspaces                                                                                |
| Simulation core | a package with no dependencies that runs in Node, in tests and, if ever needed, in the browser |
| Server          | Node.js with `ws`                                                                              |
| Client          | Vite and Three.js, with the interface in plain HTML                                            |
| Saves           | a JSON snapshot of the state                                                                   |

## Packages

| Package             | Contents                                                                                            |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| `packages/sim`      | the core: world generation, the tick, the per-player view; imports nothing from Node or the browser |
| `packages/bots`     | doctrines, the decision function that turns a view into commands, and the headless match runner     |
| `packages/protocol` | the messages between client and server, and the parser for what a client sends                      |
| `packages/server`   | rooms, seats, the clock, saves and the WebSocket endpoint                                           |
| `packages/client`   | the browser client: the globe, the panels and the connection                                        |

Tunable numbers live in one constants object inside the state, so they can be changed at run time and are saved with the game.

## Decisions

1. **The core is a pure function.** It turns a state and a list of commands into the next state. State is plain data and randomness comes from a seed. Saves, replays, tests and headless bot matches follow from this.
2. **A player is a seat in a room.** A human takes it over a socket, a bot takes it inside the process. Both send the same commands, and the core validates every one.
3. **The server computes each player's view.** Fog and the private data of other players are cut out before anything is sent.
4. **Time is server state.** Pause and speed are commands, not client settings.
5. **Static data is separate from dynamic data.** The map is sent once on joining. After that the player's full view of the arena is sent every tick, so reconnecting needs only one snapshot.
6. **The rules know no geometry.** They see cells and the joints between neighboring cells, regions that group cells, edges that group the joints between two regions, and owners. Positions and bodies are made with the map, and only map generation and the client read them.
7. **Rules run on cells and orders name regions.** Only the aim of a pressure names a cell. A view therefore has two layers: a summary per region, from which bots decide and panels are drawn, and compact lists per cell and per flow, from which the globe is drawn.
8. **The client decides nothing.** It draws the latest view. The motion of flows between ticks is cosmetic and derived from numbers the server sends, and smoothing of other values can be added without touching the server.
9. **A body is a description, and look and rules meet only there.** A body is its physics in real units, a seed, the radius, orbit and spin of the conventional scale, and seven numbers of relief. The look is one function of that description and the rules will be another, and neither reads the other. The relief is a function of a point on the body. Map generation samples it where cells stand and the client draws it for every pixel, so neither depends on how the other works: cells can be cut another way without changing the look of a body, and the look can change without touching a rule.

Because orders are standing states and ticks are slow, the game needs neither client-side prediction nor lockstep synchronization.

## Protocol

Messages are JSON over one WebSocket. A client first joins a room. A room that does not exist yet is created, from its save if there is one.

| From client | Meaning                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------ |
| `join`      | take a seat in a room; a setup with a seed and rival doctrines applies only when the room is new |
| `orders`    | orders for the seat's own power; the server stamps the seat on them                              |
| `time`      | pause, resume or change speed                                                                    |
| `triggers`  | which events pause time for this seat                                                            |
| `report`    | which report to send with this seat's views, the force report or the economy report, or none     |
| `snapshot`  | write the whole room to a file on the server, for debugging                                      |
| `tune`      | change constants, where the server allows it                                                     |

| From server | Meaning                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------ |
| `welcome`   | seat, seat token, map outline, constants, room status and the first view                         |
| `view`      | the seat's view and the events it can see; sent after every tick and after every batch of orders |
| `room`      | time and seats, sent when either changes                                                         |
| `constants` | the constants after tuning                                                                       |
| `rejected`  | orders the core refused, with reasons                                                            |
| `snapshot`  | the name of the snapshot that was written                                                        |
| `error`     | a message the server could not act on                                                            |

- A `view` also goes out at once when a seat asks for a report, and every view carries that report until the seat asks for the other one or for none. A request for the economy report may name one region, and the report then lists the cells the seat holds there.
- For every pressure a view gives the force committed and its breaches: the contacts that carry force into a cell whose siege has begun, each with the progress of that siege. The force is worked out for the coming tick with the function the tick uses, so the map and the force report agree. Breaches that start in a region the seat cannot see are left out.
- The first join of a seat returns a secret token. Rejoining that seat requires the token, and the newer connection replaces the older one.
- Everything a client sends is parsed field by field, and unknown fields are dropped. The core then checks ownership and ranges.
- Messages are compressed by the WebSocket extension. A view of the first planet is 11 to 23 KB of JSON and 1 to 6 KB on the wire. The message sent on joining is about 66 to 76 KB and about 12 KB on the wire, of which a star system of 10 to 27 bodies is 6 to 14 KB and 2 to 4 KB. No image of a body is ever sent.
- Numbers go out with four decimals. The physics of a body is the exception and is sent as it was made, with five significant digits, because its values run from shares of a hundred-thousandth to masses of 10^30.

## Server

- The server listens on the local machine unless a host is given. It has no accounts yet, so a seat token is the only protection.
- A room is saved when its last player leaves, every thousand ticks while it runs, and on shutdown. A save holds the whole state, so a restored room continues identically.
- A save written by another version of the format is set aside under another name, and a fresh game starts in its place.
- A snapshot is a debugging aid that keeps the moment a question came up. On request the server writes the room as it stands to `snapshots/<room>-<tick>.json` inside the saves folder and answers with that name. The file is a save without seat tokens, plus the seat that asked, the region it had selected and the state of the clock. It holds everything, with no fog. Copied into a saves folder, it opens as a room of its own.
- Live tuning is off unless the server is started with the tuning flag.
- The server also hands out the built client, so one process and one address are enough to play. Text files are sent gzipped, 155 KB instead of 611 KB for the script, and files with a hash in their name are cached for good.

## Client

- A body is drawn from its description alone. The client works out the relief of a body on the graphics card and keeps it as a cube map of heights and slopes: 512 texels a side for the home body, the star and the body in focus, 256 on a handheld, and 128 or 64 for another body. A pixel of a body then costs two reads of that map, and four on the home body from orbit, where clouds are added.
- A body has a map only while it is wider than 7 pixels on screen. The map is made when the body grows past 14 pixels, one body a frame, and dropped below 7. Until then the body is a speck: a point drawn as a small disc of the mean color of the body, lit by its stronger lamp and the sky, with its own glow added, never smaller than 3 pixels, so every body of a system shows from afar. A star as a speck has the mean color of its disk. The home body, the star and the body in focus keep their maps at any distance and are drawn as specks while narrower than 3 pixels. All specks are one draw call. Opening a system therefore costs the maps of the star and the home body however many bodies it has: in software 12 s for 12 bodies and 17 s for 17, where making every map at once took 16 s and 23 s.
- The relief exists twice, in the core in TypeScript and in the client in GLSL, built on an integer hash that both compute alike. Measured on every face of the cube for every body, the two agreed within 0.0003 of a height.
- The relief has a height in meters for one unit of its field: 92 000 over the pull of the body in meters per second squared, less on ice and down to 0.15 of that where the inside is still, and no more than a twentieth of the radius. The ground of a body in meters is that field, finer octaves of the same noise that fade out below the grain asked for, and its craters.
- Craters are layers of a lattice of cells in space, the pitch halving from one radius of the body. A cell whose point falls in a thin shell at the surface holds one crater there, between an eighth and a quarter of the pitch in radius, so a place is touched only by the 27 cells around it and a layer costs the same everywhere. A hash of the cell gives the place, the radius and how worn the crater is, and the share kept follows from the body: all on bare still rock, fewer under thin air, on ice and where the inside stirs, none under thick air, a sea, lava or life. Up to the bowl limit of the body, a diameter of 29 km over its pull and 4 km in ice, a crater is a bowl a sixth as deep as wide with a raised rim; a wider one is shallower with a flat floor. Craters narrower than about three grains fade out, so a coarse view leaves out only what it could not show.
- The map of a body carries craters in the same four numbers. Their slope is found exactly, not by a difference, and added to the slope of the relief, and their depth is stored along the radius, where a slope has no part, so the height of the map stays the relief without craters and what reads it elsewhere is unchanged. The shader of a solid body takes the depth out again for a body that has craters and colors by the height with it. On a float map the craters of the two sides agreed within 0.000004 of a height.
- The home body has two looks, and the distance of the camera blends one into the other. Near it the client shows a chart: colors by height and a hillshade lit from the north-west, with no night side. From farther away the star lights it, with day and night, clouds drifting over it and an atmosphere at its limb. Every other body has only the look from afar.
- The look of a body is a function of its physics, and the seed only settles details such as where a storm stands. There are three ways of drawing, and a body takes one by its mass and by whether it is wrapped in gas: a star, a body wrapped in gas, and a solid body. Inside each way the look is a set of numbers and colors that change smoothly with the physics, so bodies close in mass and warmth look alike and the cost of a pixel does not depend on where the numbers came from.
- A solid body has one shader for every skin: a ramp of colors by height, patches of a second color, cracks along steep slopes, frost from a latitude that the temperature sets, a sea where the description has one, clouds, and a deck of fog that hides the ground under thick air. The fog takes its color from the gases, orange from methane, pale yellow from carbon dioxide, white from steam and gray from hydrogen, and methane thickens it at a lower pressure. A bare rock, a rusty desert, a living world with seas and a shell of ice are sets of those numbers, and a body takes a blend of them by its air, its ice, its temperature and its life.
- A body turned fast enough is flattened at its poles by the share that follows from its spin, its size and its mass.
- A body that is not round is the same sphere pushed in and out in the vertex shader: stretched to three unequal axes and dented by three octaves of noise from its seed, by up to a fifth of its radius where it is wholly a lump. The shader finds the slope of the shape from two neighboring points, and a pixel costs what it cost before.
- A body is lit by up to two lamps: of the bodies it circles, up the chain to the centre, the two whose light an eye sees best where the body stands. A lamp has a direction and a strength, found every frame from where the two bodies stand, and a color fixed with the body, so the second lamp costs a pixel two dot products. The drawn strengths are worked out anew only when the light of a lamp has moved by a fiftieth or the temperature of the body by half a kelvin. The shadow of a ring on its body and of a body on its ring is cast by the stronger lamp alone. A third light has no direction: the stars of the sky, which light a body evenly and are all the light of a body with no lamp. The strength of each light is the conventional one of the core.
- A body that glows shows it. The glow has the color of a black body, taken a fifth cooler than the body and no hotter than 1400 K, so the hottest brown dwarf is no paler than the coolest star beside it, and its strength comes from the same scale as the lamps. A body wrapped in gas glows through the gaps in its clouds, more in its dark belts, the same on every side, and below 1600 K with the magenta that sodium and potassium leave of the light. Lava glows where it lies. A glowing body is a lamp to its moons, and it lights its own ring from the inside, less by the cube of the distance.
- Where rock melts on a solid body, the ground below a level is lava. The level follows the temperature of the place, which runs from that of the night side to that of the point under the star on a body with no air and is even under thick air, so an airless body has its lava on the day side and its lowlands melt first. Cool lava is dark crust with glowing cracks, drawn as lines of equal value of two readings of the map, and hot lava glows evenly. Fog over thick air hides it.
- Where the temperature of a body swings by more than half a percent over its year, the client asks the core for the temperature at the tick, and sets the level of the lava, the edge of the frost and the strength of the glow anew each time it has moved by half a kelvin.
- A body is approached from the side its stronger lamp lights, and where that would put the camera inside the star, as for a planet close to it, the camera stands as far aside as needed.
- The page `atlas.html` draws a sheet of bodies without a server: a row for each mass, a column for each distance from the star, a row of stars in their prime and a last row of stars earlier and later in life, each made by the generator of the core and drawn as in the game, with its class, mass, temperature and air written under it. The masses, the distances, the stars, the lives as pairs of a mass at birth and an age, `lives=1@11.4,15@0.0175`, the seed, the age of the system, the tick, the size of a picture, the distance of the eye in radii and the turn of the bodies are query parameters, and a star lighter than 0.075 of a Sun is a brown dwarf. It is the way to judge a change of the look or of the generator over the whole range at once. A sheet of 90 bodies with maps of 64 texels takes 16 s in software.
- The page `generator.html` makes a star system from a seed without a game and shows it in the scene of the game, which works with no home body. A system is made with a home, and is then the one a game with that seed gets, or without one, and the mass of its centre at birth may be given, from a brown dwarf to 60 Suns, and where there is no home its age, in a field or on a slider that runs by the logarithm from a hundred thousand to thirteen billion years, so one system can be followed from its disk to the end of its star. Seed, home, star and age are in the address, so a system can be reopened. Time runs at a chosen speed or stands still. Beside the scene is a list of the bodies, and for the chosen one every number of its description with what follows from it: density, gravity, escape speed, the temperature of a black body in its place, the reach inside which it holds moons and the one inside which it tears them apart, the lamps that light it with their light in lux and the strength each is drawn at, the looks its own look is blended from, and its conventional scale. The temperature of the moment and the lamps, each with its distance, follow the clock. A body that shares an orbit says with which, how far ahead or behind it keeps, and how often the two trade places. A button swaps the drawn scale for the real one: the same scene given a survey, with a clock in seconds that runs from real time up to a year a second.
- On the real scale the scene keeps to the sky and does not turn with the body in focus, a body shows its lit look at any distance, the camera starts on the lit side of the home, and the nearest thing drawn may stand a ten-thousandth of a radius of the home from the eye. Clouds, bands and spots follow a clock of their own, a tick for every 72 seconds and at most 16 ticks a second, so they neither freeze at real time nor flicker when a day passes in a second.
- The state of cells lies over the chart as a veil: one mesh with a color and an opacity per cell. An owned cell takes the owner's color, brighter as it is built up and slightly transparent, with the hillshade kept, so the relief shows through. Unexplored land is veiled dark, and explored land out of sight is dimmed. The veil reads the cube map of the body, so it covers land only and ends at the coast. A cell whose flag is falling keeps its veil only around its middle, a smaller patch the lower the flag. A view carries the flag of every cell the seat can see.
- A cell on screen is the land nearest to its point, as far as a reach of about two cell widths. Cell shapes are the Voronoi cells of the land points, which the client builds from those points alone. A line between two cells is drawn only where it runs on dry ground. The client finds that with the relief function of the core, sampled along the side as map generation samples it, so a line stands exactly where the map has a land joint.
- Dark lines separate regions and bright lines separate holdings. A coast needs no line, so a selected region is also shown lighter. The line where a power presses is drawn in its color, dashed while the attack is only announced. White teeth along that line mark the contacts where a siege is under way. They point into the besieged cell and reach deeper as the siege nears its end. Where force presses a cell that holds, the line stays smooth and only the force on its label tells of it. Across a strait the line is an arc from the attacker's cell to the far shore, ending in a short bar on which the teeth stand.
- The scene is the whole star system: the star, the bodies on their orbits and a sky of stars. The camera always circles the origin and the world is moved around it. Near a body the frame is fixed to that body and turns with it. Farther out it stops turning, and farther still its middle moves from the body to the middle of the mass of the system, so one zoom leads from a cell to the whole system. The middle moves only where the body stays in view: while the camera draws back from 0.9 to 3.5 times the distance of the body from the middle of the system, so the zoom from a moon of a far star leads out through its planet and its star. A click on a body or on its name flies to it. The name of a body is hidden while the body stands within 70 pixels of the one it circles, and the name of a star only where it would cover the name of the star it circles. The body in focus always keeps its name. The wheel zooms over a name as it does over the scene. The veil, the lines and the labels of the chart fade as the camera leaves the home body.
- The place and the spin of a body come from the tick through functions of the core. Between ticks the client moves them on by the time since the last view.
- Clouds and the bands of a gas giant move with the tick as well. Clouds are two layers read from the cube map of the body that slide along the latitudes in opposite directions at different speeds, so their shapes change as they pass each other. Nothing is stored or sent, any tick can be drawn at once, and a paused game stays still.
- A gas giant is drawn after photographs of the giant planets: straight bands along the latitudes, with curls and wisps kept to their edges. The bands are a table made once from the seed: for each of 1024 latitudes a color, a share of turbulence and the speed of the wind. Dark belts and bright zones take turns and narrow toward the poles, and the wind peaks at their edges.
- The cube map of a gas giant holds no relief. It holds what a flow of eddies, stretched along the latitudes, has done to the clouds: how far north or south each place was carried, and three cloud textures carried with it. The client follows that flow backward in eight passes, each one step that reads the pass before. One shader taking all the steps would be simpler, but a software renderer could not build it within 3 GB of memory. A pixel takes its color from the table at its latitude moved by the carried distance, so the edge of a band stays sharp at any zoom, waves gently where the air is calm and folds into hooks where it is not.
- The bands stream. A pixel reads the map at two places, turned about the axis by the wind of its latitude and half a cycle apart, and blends the two distances, not the two colors, so the pattern changes shape without ever showing double. Up to eight storms are worked out from the tick. A storm is an oval that drifts along its latitude. The bands bend around it as water bends around a stone, its inside is wound into a spiral that turns, and the largest leaves a wake of stronger turbulence. A pixel costs two reads of the map, two of the table and a pass over the storms.
- The look of a body wrapped in gas is a blend of eight sets of numbers by its temperature and its mass. Cold and heavy, it has brown belts with a red spot, white ovals and blue-gray wisps along the equator. Cold and lighter, it is pale gold with soft bands, and light or very cold it is blue, deep with a dark spot where it is lively and pale cyan with hardly a feature where it is calm. Warmer, its clouds are white water, warmer still it is a clear azure, hotter it is nearly black, and above 1300 K it has patchy brown clouds of dust. A blend takes the storms of the nearer set and fades them toward the middle. A thin wrap of gas is drawn behind a veil: where gas is under a twelfth of the body its bands fade toward their mean and toward the gray of hydrogen fog, so the thinnest wrap looks like the fog over a solid body of nearly the same mass.
- Any body may carry a ring, and its description gives the inner and outer edge, the density and the share of ice. A dense ring is broad with a few gaps and a thin one is a handful of narrow bands, bright where it is ice and dark where it is dust. A ring is one flat mesh in the plane of the equator, inside the orbit of the nearest moon, and its density and color along the radius come from a table made from the description and the seed. It is lit by the sums the layer of a disk uses, taken once across the whole ring: light scattered once by a flat layer, by the height of the star over the ring and of the eye. Seen from the lit side it is bright where it is dense. Seen from the other side it shows the light that passes through, so its thin parts glow and its dense parts are dark. Its grains throw light back as a matte ball does, brightest with the star behind the eye, and a tenth of it forward as dust does. The body throws its shadow on the ring and the ring on the body, each found by following the ray toward the star, which costs a ringed body one more read per pixel. The camera stands farther from a ringed body, so the ring fits the view.
- A belt is a cloud of 300 to 1800 points by its mass, half as many on a handheld, in one draw call. Each point has a circle of its own, slightly tilted, and the shader moves it along by the tick, faster nearer the star, so a belt costs the processor nothing per frame. A real belt is far too thin to see, and the points only mark where it lies, as bright as the light of the star there is drawn. Where a belt is small on screen its points thin out, the smallest first, so that they cover no more than about an eighth of it and never hide what they circle. Any body born as a star may carry belts, and a belt circles the middle of the mass that lies inside it. The camera may draw back as far as 2.4 times the widest reach of the system.
- The points of a belt lean by the height of its disk, and they fade in as its dust thins from a depth of a thousandth to a ten-thousandth, so a disk with gas has none. None is placed where the core says a belt is swept by a planet.
- Dust dense enough to be seen, a depth of two hundred-thousandths or more anywhere, is drawn as a layer with a thickness, one draw call for all the disks of a star: a home system has none, and a wild one older than a hundred million years only around a heavy belt, for a few hundred million more. The layer is a table of 384 distances, even in the logarithm: depth, height, the light of the star as it is drawn there, ice and the glow of dust hotter than 650 K. The depth of a disk falls outward by the distance to the power 1.5 and its edges are as soft as it is high. The lane of a planet between two disks with gas holds the share of dust the planet leaves, so only a heavy planet shows a gap, and the heap beyond it is a bell as wide as the disk is high there.
- A second table, 192 by 40, holds how much dust lies between the star and a place, by distance and by height in heights of the disk up to seven. The star shines from two points, four parts in 3π of its radius above and below the middle, which lights a flat disk as the limb of a star does. From this follow the bright wall at the inner edge and beyond a gap, the dark behind them, and a lit skin three to five heights up on a thick disk, higher farther out.
- The shader walks each ray through the layer in at most three stretches, split where the ray crosses the middle plane and where it rises out of the layer over the hole. A stretch has 10 steps where the disk has a skin and 3 where it is thin throughout, 6 more for each time the distance from the star changes e-fold, and never over 28, set closer near the star. A step is not sampled but summed: dust lies across the layer as a bell curve, so the dust along a step and the light scattered out of it have exact sums for a flat layer, the classic ones for a ring seen from its lit and its unlit face. A layer a few meters deep and one a tenth of its width deep are therefore one case, and the walk ends when a hundredth of the light behind is left. Up to six bodies widest in view stop a ray as spheres. A body the eye stands within ten to thirty of its radii of keeps the dust six radii off, a courtesy to the eye and not a thing a planet does, so a planet deep in a disk can still be looked at. The layer is drawn after the glare of the star and before rings and tracks, so a disk seen from its edge hides its star.
- Light is scattered once, forward by dust with an asymmetry of 0.5 and by rubble with 0.2, and shown as the light of the star is drawn at that distance, times the root of what is scattered, so that a haze a thousand times thinner than a surface is still seen. Dust the star does not reach is drawn as dark as the sky and not darker. A body is lit through the disks of its lamps: the light of a star reaches it thinned by the dust in between, read from the same table, so a planet deep in a thick disk is dark and shows by its own heat. Left out: light scattered more than once, which would brighten a thick disk by a fifth to twice; the shadow of a planet on the disk; spirals, warps and clumps. The glow of hot dust is drawn far brighter than the two parts in a hundred thousand of the star's face it really has.
- Measured where nothing but software draws, 1040 by 836 pixels with the disk across a third of them, a frame takes about 250 ms with an opaque disk and 320 ms with a thin one, against 90 ms with none and 80 ms with the flat sheet drawn before. A graphics card shades such pixels thousands of times faster, and by what clouds cost in games a disk across half of a 1080p view should take about half a millisecond on a middling card and a few on one built into a processor.
- The track of an orbit is the path of a body about the middle of the mass it circles together with itself. Where the body, with all that circles it, has three hundredths or more of that mass, what it circles has a track about the same point as well. A track fades as it shrinks on screen, between a radius of 12 pixels and one of 5, so the tracks of moons do not smear a far planet. The 256 points of a track are counted from where the body stands, crowded toward it by the cube of their number and stored as offsets from it, and worked out anew when the body has moved and the track is in view. The line then passes through the body however small the body is against its orbit, where points spread evenly and counted from the middle of the orbit would miss a planet at 30 AU by fifty of its radii and tremble by hundreds of kilometers. Specks are stored as offsets from the body in focus for the same reason.
- The name of a body behind the body in focus is hidden.
- The star is drawn hot and not lit, after photographs of the Sun: an even disk that darkens and reddens toward its limb, a fine grain, a few small dark spots and a soft glare. Its cube map holds no relief but a field of coarse cells, a coarse noise and a net of cells the size of supergranules, 30 thousand kilometers on a Sun, along which the brighter threads run.
- The grain is not in that map, because granules are far too small for it: about 1,300 kilometers on the Sun, four million of them. They are read from a three-dimensional texture of cells, bright inside and dark along their lanes, that repeats every sixteen cells. It is made once on the graphics card, 128 texels a side with its mipmaps, about 2.4 MB, and every star shares it. A star reads it at its own pitch: against the radius a granule is as wide as on the Sun and narrower on a cooler star, by the temperature to the power 1.3 over the gravity, a little over half as wide on a red dwarf. The sphere cuts through the cells, and the place read rises through the texture by a cell every eight ticks, so granules swell, split and fade where they are and nothing slides. Every 240 ticks the pattern dissolves over 48 ticks into a fresh one, read elsewhere in the texture, so the pitch never drifts by more than a twentieth. From afar the mipmaps average the grain away and the disk is even, as the Sun is in a photograph of its whole disk.
- Spots are not read from a map. A star has up to sixteen active regions, and the client works out from the tick where each stands and what it holds. A region is a group of up to six spots along an axis: a leading part, ahead as the star turns and nearer the equator by an angle that grows with the latitude and scatters widely, and a following part behind it. The leading part is one compact spot, sometimes with a companion, the following part is one to three spots, and a large group may have pores between the two. The larger part leads in seven groups of ten, and one group in twelve is a lone spot. A group emerges quickly and spreads to its length, its following spots fade first and break up as they go, and the leading spot outlasts them and grows rounder; the next group of the region rises elsewhere in the belts on either side of the equator.
- The sizes of the groups are those of the Sun. The size of a group is drawn from a log-normal law, so most are small and a few are large, and its length and its life grow with it. A yellow star at the height of a strong cycle carries about twelve groups at a time, six on the side in view, and its spots cover about a thousandth of a hemisphere, as on the Sun at an ordinary maximum; the many groups of the Sun too small to see are not drawn. An orange and a red star have slightly larger spots.
- A spot has a dark core with a ragged outline and, once it is large enough, a paler ring in which the grain is stretched into fine rays that creep outward. A number for each spot says how far its core is broken into a cluster of small ones, low for a leading spot and high for a following one. Brighter threads lie around a region, rise and fade with it and stand out toward the limb.
- A star has up to sixteen prominences, and they are not tied to its spots. Each is a curtain that stands on the surface along an arc: three thin sheets side by side that wave a little, so it has some depth from any side, and all the prominences of a star are one mesh. Its top is uneven and its body is threads, both read from the map of the star, and it may stand on legs with arches between them. More than half are quiet ones far from the spots, up to seventy-five degrees of latitude, lying mostly east to west, a sixth to six tenths of a radius long and 17 to 50 thousand kilometers high for a Sun; the rest lie in the belts of the spots, low short ones along any line and single loops. One in three ends by erupting, its middle rising a third of a radius as it fades. A prominence is drawn only where the line of sight misses the disk, so it shows at the limb, also from behind it, and not against the star. Against the disk of another star it leaves a faint dark red shadow, as a filament does through a hydrogen filter. At its densest it is as red as the limb, so it is always dimmer than the limb, and it is drawn after the glare of its star and covers it: three.js orders two transparent objects at one place by their creation, so the glare is made first and the mesh of the prominences has its bounding sphere at the center of the star. A star with no grain has none.
- In white light, as the disk is drawn, a prominence could not be seen at all. They are drawn as through a hydrogen filter, on purpose, and so is a thin red fringe of uneven height just above the limb.
- How spotted a star is follows from its Rossby number, its day over the time its convection takes to turn over. Its activity runs by the logarithm from 0 at a Rossby number of 3 to 1 at 0.13 and below, and is 0.13 for the Sun. Above the activity of the Sun the spots grow, up to three and a half times wider, and no core is wider than 0.07 of a radius.
- A star of low activity has a cycle of about 60,000 ticks, a quick rise over three tenths of it and a slow decline, and a draw makes the cycle of one star stronger than that of another. Whether a region rises is settled when its turn comes, by the level of the cycle then, so nothing appears or vanishes at once. Regions rise at 28 degrees of latitude when a cycle starts and at 8 when it ends, scattered by 6 degrees, on a yellow star, and twice as far out on a red one. Between an activity of 0.45 and 0.9 the cycle fades, and regions rise at any latitude, mostly high. Above 0.7 a star has a lasting cluster of large spots at one pole, and above 0.85 at both.
- A flare is a patch of threads far hotter than the surface, bright within two ticks and fading over eight. A star at full activity flares every few hundred ticks, the Sun a hundred times more rarely and far more weakly. Prominences are fewer at the low of a cycle and up to 1.8 times taller on the liveliest stars.
- The drawing departs from the Sun on purpose in four ways, all meant to be mild. At the low of its cycle a star keeps a quarter of its regions, about 300 millionths of a hemisphere under spots, where the Sun is nearly bare for months. Time is compressed: a region lives about 1400 ticks and a cycle 60,000, where a tick is 72 seconds on the real scale, against days to months and eleven years. And the liveliest red dwarfs carry spots on about 4 percent of the surface, less than the tenth to a half measured on such stars, because a star has sixteen regions at most. And a prominence is drawn several times brighter than a hydrogen filter shows it, where it has roughly a tenth of the brightness of the disk.
- Every shade of the star comes from one number, the temperature of a place relative to the surface: lower in the lanes between granules, in the ring and the core of a spot and toward the limb, higher in the bright threads. It is raised to a power for each color channel that follows from the temperature of the star, so a cooler place is both darker and redder, and a cool star has a darker limb than a hot one. The glare is worked out along the line of sight of each pixel. How far the line passes from the star gives its strength, so it follows the true outline of the disk wherever the star is on screen, and where the eye and the first body on the line stand along it gives the part of the glow that lies between the two. A body in front of the star hides the glare, a body behind it is veiled by it and a body beside it by half, with no edge across the body, and nothing jumps when the star leaves the view. Another star is the exception: its disk hides the glare wherever it stands, because a glow so much fainter than a disk could not be seen against one, and the dark limb of the nearer star then shows against the disk of the farther. Where the glares of two stars overlap their light adds up and levels off at the strength of a glare at the limb, so the corner between two disks is no brighter than the sky beside one. It is drawn as a square that faces the screen, or over the whole screen once the eye is within twice its reach, at a depth just behind the star, just before the body it veils or just behind another star on the line, so it never covers a disk. The six nearest of the bodies within that reach and of the other stars at any distance are given to it as balls, flattened as the bodies are. It takes its color from the limb and fades evenly all round. A pixel of the star costs two reads of its map, two of the grain and a pass over the sixteen regions, and the spots of a region are looked at only inside the circle that holds them, so the cost does not grow with the number of spots, and a flare costs one more exponent while it is lit. A pixel of the glare costs no read, and one read within a twentieth of a radius of the limb, for the fringe. The prominences of a star are one draw call of 14,000 triangles, and cost only the pixels they cover.
- The look of a star follows from its temperature, between eight sets of numbers from 2600 to 40 000 K, and its spots from how fast it turns. Above about 8000 K a star is white and then blue, has no grain and no spots, and is brighter at its poles while it turns fast, which a star swollen past three times the radius of its main sequence no longer does. The color of the star tints the light on every body.
- A swollen star needs no look of its own, because the width of a granule already follows from the temperature over the gravity: a red giant at the tip of its climb has seven cells to its radius where a Sun has five hundred. Cells that coarse are read softer, at a coarser level of the grain, pushed out of line by the noise of the star map, and overlaid with a finer layer of the same grain and with broad warm and cool patches, and their contrast grows by up to four times, as convection is more violent where gravity is weak. They change as slowly as they are wide, down to a tenth of the pace of the Sun. A cool giant turns slowly and is as quiet as an old Sun.
- A star denser than 10^7 kg/m³, a white dwarf or a neutron star, is an even disk of the color of its temperature with a dark limb and a glare, with no grain, no spots and no prominences. A cool white dwarf is therefore orange and not white.
- A black hole gives no light and is drawn by what it does to the light behind it: a black ball 2.6 horizons in radius, the shadow a hole casts, and a sky of stars bent around it. Each star of the sky is moved outward from the hole by the angle a point lens gives, with the Einstein angle of a hole seen from the distance of the eye, the root of two horizons over that distance, and made brighter as a lens does, up to three times. The same stars are drawn once more for each hole as their second image, mirrored inside that ring and dimmer. The sky is one cloud of points, so a hole costs one more draw of it and nothing per pixel. The bending is that of a weak field, wrong close to the shadow, and the bodies of the system are not bent, only the sky.
- Flows are particles moving between the centers of neighboring cells. A particle stands for a fixed portion of cargo, so their number on a joint shows the volume. A strait is a dashed arc over the water.
- A garrison is a white square on its cell, and the top bar shows the force of the player against the room in all their garrisons.
- The panel holds the orders for the whole power, the army with its forward dial and the leaning, next to those for the selected region. A view carries, for each holding of the seat, the room the simulation is building toward, so the panel shows it whether the army placed it or the player fixed it. The garrison field of a region is empty while the army places its room.
- Roads are sand-colored lines between the centers of neighboring cells, wider with every grade. A view carries the grade of every joint the seat can see. A strait shows its road by the width of its arc.
- Labels and panels are plain HTML over the canvas. A panel is rebuilt only when its structure changes; between rebuilds only its numbers are updated.
- A region's label stands on the center cell of the region. Where the player holds cells in the region it stands on one of them instead: the cell nearest the middle of the largest connected group of the player's cells. A pressure label that would cover the label of its region is moved just above or below it.
- The force total in the top bar opens a report meant for debugging. One table lists the player's regions with the force resting in the garrison, standing at a front and on the move, the orders that ask for it and the region the moving force is heading to. The other lists, for every line of pressure the player takes part in, each pressed cell with its defense, the attacker's force facing it, the pressure on it and the most its contacts can carry, the progress of the siege and whether the cell can fall. The server works both out with the functions the tick uses, only for a seat that has the report open: the client asks when the dialog opens and tells the server to stop when it closes. An open report adds about 3 KB of JSON to each view of that seat.
- The matter total in the top bar opens the economy report, also meant for debugging. Three tables give one tick of the whole power: matter made and what it was built into, energy made, needed and met, force built and lost, each with what was lost on the way and with fallen flags. A table of branches shows the levels built, the share the cells would build now and what each branch makes. A table of regions shows for each the matter and energy made and used, what it builds, what building waits for matter, and what it sends to and gets from other regions. Picking a region lists its cells in the same way, with the progress of the next level. A region or a cell whose flag is falling says how many ticks are left, and the panel of a region says the same.
- The tick can keep a ledger: what every cell made, spent, needed and lost, and every hop of matter, energy and force. For the economy report the server runs the coming tick on a copy of the state with a ledger and sums it by cell, region and power, so the report shows the effect of an order at once, also while time is paused. A normal tick keeps no ledger. A report costs about as much as a tick. It adds 9 to 12 KB of JSON to a view, and about 0.9 KB more for every cell of the region picked.
- The `Snapshot` button in the top bar asks the server for a snapshot and shows the name it was given.
- The scene is drawn on demand: after a new view, a camera move or a resize, and continuously only while time runs and something on screen moves, flows on the chart or bodies seen from orbit. A paused game with a still camera draws nothing.
- On the chart a frame is about 32 draw calls and 65,000 triangles. The cube maps take about 17 MB for the home body, 8 MB for the star, which is kept at 8 bits a channel, with 2.4 MB once for the grain of every star, and 1 MB for every other body on a desktop, and 4, 2 and 0.3 MB on a handheld, and a visited body takes as much as the home body while it is in focus. Where the graphics card cannot draw into float textures the maps fall back to 8 bits a channel, and a gas giant keeps straight bands without eddies. The speed of the shaders on a real phone has not been measured: the development machine draws in software, where a frame takes seven times longer than before bodies had a look.
- One page serves desktop and handheld. On a narrow upright screen the panel becomes a sheet under the globe that opens on selecting a region, and on any small screen the top bar keeps time controls and totals and moves the rest into a menu. Targets grow where the pointer is coarse.
- The `Aim` button of an attack makes the next tap on the globe pick a cell instead of a region. The aim is marked with a cross in the attacker's color.
- Dragging turns the globe at the speed of the surface under the pointer at any zoom. A tap selects only when a single pointer went down and came up in place, so a pinch never changes the selection.
- On a handheld the client pauses the game when the page is hidden and caps the motion of flows at 30 frames a second. On returning after half a minute or more it opens a fresh connection before dropping the old one, because a suspended page can keep a dead socket that still looks open.
- The seat token is kept in the browser's local storage, so reloading the page returns to the same seat.
- In development the client runs on Vite at port 5183 and connects through its proxy to the game server on port 8787. Vite listens on 0.0.0.0 and proxies WebSocket connections on `/socket` to the game server, which stays on localhost.

## Bodies

- A system is made by the core from the seed of the world, in a stream of random numbers of its own, so a change of the generator leaves the cells and regions of a seed where they were. The seed of the home body is drawn first. Names, the seeds of the other bodies and their places on their orbits come from a second stream, so a change of the physics leaves the names of a system alone as long as it has the same bodies.
- The core also makes a system with no home, for the generator page and later for other stars. Its star is drawn between 0.08 and 2.5 solar masses unless one is given, and seven times in a hundred its centre is a brown dwarf of 0.013 to 0.074 instead. Its orbits number up to twelve and nothing on it is alive.
- A system has an age: 2 to 8 billion years with a home and 0.1 to 10 without, and for a star in its prime never more than four fifths of the time it spends on the main sequence, which is 10 billion years for a Sun and falls with the mass to the power 2.5, with three million years added that the heaviest stars do not go below: 8.6 million years at 20 Suns.
- A star is its mass at birth and its age, and one function of the core gives what it is now: its mass, radius and light, the widest and the brightest it has been, and the time since it ended. On the main sequence it keeps the radius and the light of its mass, and the light grows with the mass to the power 3.5 up to 20 Suns and 2.3 above. Four stages follow, each counted against the main sequence: a turn toward the giant branch, 8 percent of it for a Sun and half a percent above six Suns; a first climb, 6 percent for a Sun and less by the square of the mass; helium burning, 130 million years or 15 percent where that is shorter; and a last climb of 15 percent of that. A star lives between 1.11 and 1.19 of its main sequence.
- Through those stages the light goes from twice that of the main sequence to 2500 Suns at the tip of the first climb for a star under 1.8 Suns, which falls back to 50 when helium lights. From 2.4 Suns helium lights quietly, at 250 Suns of light times the mass over 2.5 to the power 2.5 and no less than 2.4 times the main sequence, and burns a fifth below that. The last climb ends at 4000 Suns times the mass to the power 1.2, or at three times the main sequence where that is more.
- The radius of a red star follows from its light and mass by the fit of the giant branch of Hurley, Pols and Tout, 170 radii of the Sun at the first tip of a Sun and 240 at its last, and it is no cooler than 2800 K times the mass to the power 0.08, which keeps red supergiants near 3300 to 3600 K and under 1300 radii. While helium burns a star under 1.8 Suns stands a tenth warmer than that branch. From four Suns it loops to one and a half times warmer and back, and from twelve Suns to three times, so one star is a red and then a yellow or white supergiant. Above 25 to 45 Suns a star no longer turns red, and above 25 to 35 it ends bared to a core of two to four radii with 45 percent of its mass, a Wolf-Rayet star.
- What is left follows from the mass at birth. Under eight Suns it is a white dwarf of 0.394 Suns and 0.109 of that mass, with the radius of a cold degenerate body, 8700 km at 0.6 Suns and none at 1.44, and a light that falls with the time since by the power 1.4, as Mestel found: 23 000 K after fifty million years, 8000 after a billion and about 4000 after ten. From eight to twenty Suns it is a neutron star of 1.2 to 1.8 Suns and 11.5 km at two million kelvin, less by the root of its age over thirty thousand years, with a day of 0.01 to 0.1 s that grows by the root of its age over ten thousand years. Above twenty it is a black hole of three tenths of the mass at birth, as wide as its horizon, with the temperature and the light of Hawking, which are next to nothing, and a day of milliseconds.
- A giant turns as slowly as it has swollen, its day growing with its radius, and a cool one has braked as a Sun does: its day is no shorter than 2.2 times the time its convection takes to turn over. A white dwarf turns in a quarter of a day to two and a quarter.
- The name of a star is read off its physics like any other. A star-born body is a black hole where it is no wider than one and a half horizons, a neutron star above 10^13 kg/m³ and a white dwarf above 10^7. Otherwise its color follows from its temperature, blue-white from 11 000 K and blue from 30 000, and its size from its radius over that of the main sequence at its mass: a star under 1.3 times, a subgiant under 3 and a giant beyond, a supergiant from eight Suns, and a Wolf-Rayet star under 0.7.
- In a system with no home a draw from a sixth stream of random numbers, so that a system whose star is left in its prime stays what it was, settles when in its life the star is met. Four in a hundred have a heavy star of 2.5 to 60 Suns, mostly the lighter ones, met between a twentieth of its life and 1.6 of it: half still burn, one in ten is a giant or a supergiant and two in five are a fresh remnant. Three in a hundred have a star of 1 to 2.5 Suns met between its main sequence and its end, and seven a star of 1 to 8 Suns met after its end, up to twelve billion years. Three more are met young, between 300 thousand and 100 million years, evenly by the logarithm. The rest are in their prime as before. The generator page may give the age, with the mass or without.
- Those shares are chosen, not counted. Near the Sun about six stars in a hundred are white dwarfs and under one is a giant, which the generator keeps close to. A blue-white star is one in a thousand there and a blue one or a supergiant one in millions; they are made about one in seventy, one in a hundred and fifty and one in a thousand, so that they are met at all. A star in a thousand there is younger than ten million years, and three in a hundred are made young so that disks are met. Neutron stars and black holes are about as rare as in the Galaxy, two in a thousand each, but only young ones are made, within six tenths of the life of their star after its end, where most real ones are billions of years old, cold and dark.
- Before the main sequence a star is wider by the cube root of one plus a third of the time still to go over the time gone: 2.4 radii for a Sun at a million years, 1.26 at ten million and its own at forty million, when it settles. That time falls with the mass to the power 2.5 above a Sun and grows with its inverse to the power 1.4 below, a billion years at a tenth of a Sun. The temperature falls with the width to the power 1.175 and stops at 4300 K times the mass to the power 0.16, the track of Hayashi, so a young Sun gives 1.8 of its light at a million years and half of it at ten million, and a red dwarf keeps its temperature and only shrinks. A star of three Suns or more is never dimmer than it will be. An age under a hundred thousand years is read as that. A young star turns in the day of a fast star times its width, and is named a T Tauri star while it is 1.3 times its settled radius or more, a Herbig star from two Suns. The widest radius and the brightest light of a star are counted from the main sequence on, so its youth swallows nothing and costs no body its air or its ice.
- A system is laid once, as it was born, and then read at an age. The seed lays it around its stars in their prime, at the age the system would have if nothing were said of its star: the stars and their orbits, the ladder, the frost line, what a body is made of and the gas a young star took from it, its moons, its ring, its name and every angle. None of that is drawn again for another age, so one seed is one system at any age and the generator page can follow it through the life of its star. A system with a home is always read at the age it was laid for.
- Reading at an age gives each star what it is by then and each body its place and its state. Orbits widen by the mass at birth over the mass now, as orbits do around a star that sheds mass slowly, and a moon stands where tides have brought it by then. Light, temperature and air are those of that day, with a gas kept only if the body held it at the hottest it has been, under its star at its brightest. A body of ice that was warmed above 200 K then and is too light to hold steam has lost its ice and is rock, as the moons of a giant planet are around a white dwarf; a heavier one keeps its water as steam and is named a steam world while it is above freezing. A ring of ice is lost above 200 K and a ring of dust above 1200 K. A planet near enough to be held to its star by that age turns with it, and its oval is a tenth of what it was.
- What a star takes is gone for good. A body whose nearest point lay within one and a half of the widest radius its star has had was swallowed, and so was a companion star within one and a half of the widest radii of the two together. A planet that the widening has carried past the hold of its star against a companion, or inside the distance a pair now keeps clear, is lost, and so is a star whose orbit no longer nests outside the one within it, or the outermost star of a group that has outgrown its room, each with all that circled it. Neighbors on the ladder were spaced around the star at birth, and a lighter star lets each of them reach farther: where two no longer keep the six Hill radii the ladder asks, the lighter of them is lost. Those limits are read at the age asked for and just after the end of every star before it, when the masses change, so what one star lost does not return under the next.
- A body is laid whole and read as far as it has grown. A planet that holds a hundredth of gas or more took it from the disk, so it is whole within the life of the gas, 2 to 6 million years around a Sun and longer by the root of the mass around a lighter star, at a time drawn in the second half of that life, and its mass grows with the cube of the time: a core first and the gas at the end, by the share a body of that mass holds. Any other body is whole after 30 million years times the root of its year in years, half to twice that by a draw and never more than a hundred million, and grows evenly. A body is listed from a twentieth of its mass, and not while it would pass within four radii of the young star. A moon and a ring follow their planet: they go from nothing to whole as it goes from six tenths of its mass to all of it. A body that shares the orbit of another is there only once the system is a hundred million years old. What falls on a growing body warms it by its own pull as light would, which leaves a core that gathers gas molten. These draws come from a seventh stream, so a system older than a hundred million years is what it was.
- The disk of a young star is what its bodies have not gathered yet, kept as belts are: a disk has a mass of gas beside its mass of dust and rock. Solids lie as in the nebula of the Sun, 70 kg/m² at 1 AU times the mass of the star, less with the distance to the power 1.5 and four times more beyond the frost line, from the inner edge of the zone, or from where a black grain would be at 1500 K and turn to gas, 0.07 AU times the root of the light of the star in Suns, to 1.5 times the farthest orbit a planet may have, or to the hold of a companion. Beyond three quarters of that reach the dust thins out, by the fourth power of the distance over it in the exponent, so the edge of a disk is soft and four fifths of its dust lie in the inner half. Every planet and every belt to be has the part of the disk nearer to it than to its neighbors. Around a planet what is left falls with the square of what the planet still lacks, and the planet clears a lane four Hill radii to each side. Around a belt it falls with the square of the time left to a hundred million years, down to the belt, as the edges close in on it. The gas is two hundredths of the mass of the star, lies evenly along the radius and thins toward the same distance, loses nine tenths over the first four fifths of its life, and in the last fifth leaves from the inside out through a growing hole. With the gas the solids count as grains of ten micrometers, the size that carries the area of dust ground between a tenth of a micrometer and a millimeter, and the disk is opaque nearly to its edge. Behind the hole and after the gas they are rubble of a meter that collisions wear down: one over the depth of a disk without gas is one over what its mass gives as such rubble, plus its age over 200 of its years. The dust near the star so goes first, a belt thins as the inverse of its age whatever its mass, and a mature system differs with age in that alone. The 200 is chosen between the 40 that gives the dust of our own asteroid belt today and the 600 of the brightest disks seen. Parts that touch are one disk, and the depth written for a disk is its mean.
- A disk is as thick as its grains are fast, and its height is written as one deviation of the grains from the middle plane over the distance. Dust rides the gas, which stands as high as the speed of sound over the speed of the orbit: 0.033 at 1 AU of a Sun and more by the fourth root of the distance, for 170 K at the frost line falling with the root of the distance. Where the gas is thin the dust settles below it, by the root of one plus the Stokes number of a grain of a micrometer over a turbulence of 0.0003: the finest grains carry the lit skin and settle last, so the disk flares to its edge and flattens as the gas goes. Without gas a disk around a star is stirred by the heaviest planet of its zone to twice the Hill radius of that planet over its orbit, 0.14 beside a Jupiter, which is the 11° of the asteroids. It is never under 0.04, the least for fine dust under the light of a star, nor over 0.3, and the stirring takes the hundred million years the belts take. A disk that nothing stirs is a ring: its grains meet gently and it is ten of them deep. A planet thins the gas along its orbit to one part in one plus 0.04 times the square of its mass over the star's, over the fifth power of the height of the gas and the turbulence, so a Jupiter leaves a few thousandths and a Neptune nine tenths. The list of disks keeps the lane empty, and the client fills it by that share. Dust heaps where the gas is densest again, ten Hill radii beyond such a planet, up to three times what lies around for a planet that empties its lane, a number chosen. A belt holds nothing where a body would circle four, three, five halves, seven thirds or two times for each turn of a planet outside it, within a part in 70 of that distance for a planet of a thousandth of its star, by the root of the mass and not at all under a part in 300.
- A zone lit at birth by 2000 Suns or more, the light of a star of eight, has no planets and no belts, as such light clears a disk before they form. A star that explodes throws off most of the mass of its system at once, so a neutron star is alone and a companion that has exploded is gone. A black hole forms without that and keeps its companions.
- When every body is made the tree is put in order of mass, so that no star circles a lighter one. A star that has shed mass may be lighter than a star listed as circling it, and the two then change places: the heavier takes the seat and the orbit of the lighter, the lighter circles it on the same oval turned half round and keeps the planets and belts that lay inside that orbit, and whatever circled the two from farther out circles the heavier. This is done from the innermost groups outward until it changes nothing, and the bodies are numbered anew, each after what it circles and in the order of its orbit. Nothing moves by it: over 12 900 bodies the places at any time stayed the same within a hundred-thousandth, the rounding of one angle. A system where no star has shed mass is left as it was, a system with a home among them.
- The life of a star leaves out much, on purpose. A star does not brighten along its main sequence and keeps its whole mass until its last stage. No mass passes between stars: a companion that a giant reaches is gone, where a real one would end as a close pair with the white dwarf or merge with it. The limits between stars are not followed through the shedding itself, only read after it. Old neutron stars and black holes, planets formed anew around a pulsar and the dust a white dwarf gathers are not made.
- A young system leaves out as much. Bodies grow where they will stay and do not migrate, and their orbits are as round or as oval as they will be. The first hundred thousand years, when the star is still inside its cloud, are not made. The light of a young star is not counted against what its planets keep, though a red dwarf, brighter for hundreds of millions of years, would dry the worlds near it. In the core the disk shades nothing and pulls nothing, a star too bright for planets has none, and two young stars too wide to stand apart are shown as one until they have shrunk.
- Orbits begin as near as four radii of the star or 0.02 AU for a Sun, where a black body is at 2000 K. The first orbit of a system with no home is drawn so that about one system in twelve has a world with molten rock, and one home system in ten is given such an orbit inside its inner ones. The scale of the orbits follows the light of the star and, for a centre dimmer than the dimmest star, stops shrinking.
- The star is drawn between 0.3 and 1.6 solar masses, and its light, radius and temperature follow from the mass by the relations of the main sequence. The home body stands where the light is that of the Earth, within a tenth. Up to two orbits lie inside it and up to five outside, each 1.45 to 2.1 times wider than the last, and an orbit is filled 85 times in a hundred.
- The day of a star follows from its age and its temperature. It is the time its convection takes to turn over, which the temperature gives and which is 13 days for a Sun, times a Rossby number that grows with the square root of the age, is 2 at the age of the Sun and stops at 2.2. A Sun thus turns in 4 days at a hundred million years, in 9 at six hundred million, in 26 at 4.6 billion and hardly slower after. A star lighter than 0.6 of a Sun keeps its fast spin longer and then loses it faster, the lightest going from a day at a hundred million years to four months at the age of the Sun. No star turns faster than 0.4 to 1.5 days, which is the day of every star too hot to have a convective envelope, and a draw spreads the day by a quarter either way. A companion star locked to a close orbit turns with it at any age, and is as lively as a young star.
- The mass of a body is drawn by where it forms: mostly less than three Earths inside the frost line, mostly giants of 50 to 3000 Earths just beyond it, the heavy ones rarer, and ice giants and small icy bodies farther out. Four bodies in a hundred inside the frost line are giants that moved in, and twenty where a black body is hotter than 800 K. No body is heavier than a hundredth of its centre times the square root of the mass of the centre in Suns: ten Jupiters for a Sun, a fifth of a Jupiter for the lightest star and 5 to 70 Earths for a brown dwarf.
- A brown dwarf circles the star as a companion in six systems in a hundred with no home and three with one. It stands 2.5 to 4 times farther than the outermost orbit and has between thirteen Jupiters and 0.074 of a Sun, and no more than 8 percent of the star. The planet inside it keeps within eight tenths of the room the published fit leaves inside a companion of that mass: the orbit of the dwarf is made rounder for it, and wider where a round one is not enough. The centre does not move for it.
- A body is wrapped in gas when the weight of its hydrogen and helium would press more than 1000 bar on what lies under them. Below that it is a solid body and the gas is part of its air. A body of nothing but gas is wrapped at any size, as a giant star is, whose own weight at its surface presses far less.
- A body wrapped in gas has heat of its own. For a Jupiter of 4.5 billion years it is 100 K, it grows with the mass to the power 0.6 above a Jupiter and 0.25 below, and falls with the age to the power 0.3. On a body lighter than a few Jupiters it is scaled by the activity of the body, from about half to a third more, as Uranus has almost none and Neptune much. Close to the least mass of a star a second term rises to the temperature of the lightest star, so the two meet. This gives 400 K at ten Jupiters and 1070 K at 52, and 1700 K for those 52 at a billion years. The temperature of the body is its own heat and that of balance with the star taken together as fourth powers, and the power it gives off is stored as its light.
- Every body also carries the light and heat that reach it, in watts on a square meter, 1361 for the Earth: those of the star, and those of whatever it circles, which sends out heat by its temperature and size. The sum sets the temperature of the body and decides whether it formed inside the frost line. Around a planet it adds next to nothing. Around a brown dwarf of 1000 K it is everything: a moon at three radii is at 380 K and one at eighty at 80 K, where the star alone would leave both at 15 K, so the near moons are dry rock and the far ones ice.
- Light for the eye is the power of a black body weighed by the sensitivity of the eye across the visible wavelengths: 93 lumens to a watt at the temperature of the Sun, 17 at 2900 K and a seven-thousandth of one at 1000 K. Daylight on the Earth is then 127 000 lux, and a surface at 1000 K has the brightness of a dim screen, 2.6 candela on a square meter.
- A system is a tree of bodies with one rule of motion. A body, with all that circles it, circles the middle of the mass of the body above it and of those of its children that are nearer, each with all that circles it, and it moves that middle by its share of the whole. No node stands for a middle, and the rule does not ask what a body is: two stars, a star and its planet, a planet and its moon and groups nested in groups move by it alike. The core works out the places of all bodies at a tick in one pass from the middle of the system inward, on the drawn scale or the real one, and the middle of all the mass stays where it is. The period of an orbit counts all the mass the body circles that middle with: the body above, its nearer children and the body itself, each with all that circles it. The pull of the other bodies on a body is then what its path asks for, within a ten-thousandth for most and a few hundredths at worst, where neighbors tug at each other.
- Stars are made as stars form, by splitting. A star has a companion with a chance that grows with its mass: 46 in a hundred at a solar mass, a quarter of a hundred more or less for each tenfold of it, between 15 and 80, and three tenths of that in a system with a home. Each further companion of the same star, and each companion of a companion, is three tenths as likely again. Of systems with no home about 65 in a hundred are single, 28 are pairs, 6 are threes and one has four stars or more, in every nesting: a pair with a far third, a star with a far pair, two pairs, and deeper. Nothing caps the number, and each level only needs room inside the one above.
- A companion has 15 to 100 percent of the mass of its star, and is a brown dwarf where that falls below the least star. Its orbit is drawn around 40 AU times the mass of the star in Suns to the power 0.8, a decade and a half either way, between four times the two radii and what the level above allows. An orbit shorter than three days is round, one longer than a hundred days may be stretched by up to 0.6, and orbits lean by up to 40 degrees once they are wider than 1 to 100 AU. Two stars closer than 20 days apart are held to each other.
- Three published limits keep nested orbits lasting, each taken with a margin. A group inside a wider orbit holds when the nearest point of the wider one is beyond 2.8 times its size, more for a heavy or stretched outer body (Mardling and Aarseth), taken 1.3 times over. Around one of a pair, orbits last out to a share of the distance between the two, 0.27 for equal masses on a circle and 0.12 at a stretch of 0.5, taken at 0.8. Around both they last from 2.4 times that distance, 3.6 at that stretch, taken at 1.15 (Holman and Wiegert).
- Planets are laid by one ladder of orbits in every zone the stars leave: around a star inside its nearest companion, around a group between two companions, and around all. A zone closed on the outside holds planets only where it spans a decade. The planets of a companion lie in the plane of its equator and those around a group in the plane of its orbit, and each is given the light of the stars outside its zone at their mean distances. A brown dwarf formed in a disk may end the open zone of the first star. In a system with a home, a companion that would leave the home no zone is moved outward or inward until it does, or dropped.
- A body born as a star is known by having no iron, rock or ice. What circles it is laid on the drawn scale as planets are, and its disks are belts.
- The core gives the same system as a survey: every body with its real radius and orbit in place of the drawn ones, in radii of the home or of the Earth where there is no home, its year and day in seconds, its rings and belts at their real edges and the sway of a body on a shared orbit as it was drawn, before the drawn scale parted the two. Every function of place and time then works on a survey as on a sketch, with seconds for ticks, and the scene draws either.
- The stars beyond the first are drawn from a fourth stream of random numbers, and the first companion from the first six numbers of the third, as the second star was before, so a system that stays single is what it was.
- A body may share the orbit of another. It has the same parent, orbit and period, and stands ahead of the other by an angle that is a function of the tick: a middle, a sway either way and a period of its own. Sixty degrees ahead or behind with a small sway is a body at one of the two points where such a place lasts. Half a turn with a sway almost as wide is a pair that chase each other round one orbit. The one on the wider orbit falls behind, so the two orbits differ by a share that changes sign each time the angle turns back, each body moved against its mass, and the middle of the two keeps the mean orbit. Bodies on one orbit move the centre above them as one, and the scene draws one track for them.
- A place at sixty degrees lasts while the two bodies have less than a twenty-seventh of the mass they circle. Its swing takes one year over the root of 27/4 of that share, and the orbits differ by the sway times the root of three times the share. A chase lasts below four ten-thousandths. Its orbits differ by 1.6 to 4 times the root of 8/3 of the share, the two come no nearer than one over the square of that factor in radians, and a round takes four thirds of a year over the difference, which gives about eight years for Janus and Epimetheus.
- At the rim of a dense ring of a body in gas, once in thirty, two moons of like mass, no more than five to one, chase each other. One moon in five of such a body, of those within a twentieth of its hold, has a small one at sixty degrees, of a millionth to a ten-thousandth of its mass, and three in ten of those have one at each point: farther out the star shakes such a body loose, and six or seven moons in ten of a body in gas are near enough. About one system in a hundred has a planet on the orbit of a planet of ten Earths or more, of a thousandth to a tenth of its mass, where a year there is longer than ten days. All are drawn from a fifth stream of random numbers, their names too, so the other bodies of a system stay what they were. On the drawn scale two bodies on one orbit keep at least one and a half times their radii apart.
- Eight solid planets in a hundred that have a moon have one of 5 to 50 percent of their own mass, and are double planets. The home never is.
- The lamps of a body are all the bodies of the system whose light an eye would see on it, down to a thousandth of the light of the sky: the glow of each by the square of its radius over the distance, which is the size of the orbit that parts the two in the tree. A star is a lamp to everything in its system and a brown dwarf to its moons. The scene draws the two strongest and adds the rest to the even light of the sky. That light is counted at the mean distance. The core also gives it at a tick, from the real distance between the two bodies at that tick, and over a year the two agree.
- The conventional scale of light takes the lamps of a body, the light of the sky, 0.0002 lux, and the glow of the body itself, each as the light a surface of albedo 0.3 would send back. The strongest is drawn at the power 0.1 of its ratio to daylight on the Earth and no brighter than 1.35 of it: a half at thirty times the distance of the home, a third at 250 times. Each weaker one is drawn at that strength times the power 0.3 of its share of the strongest. The sky is never drawn darker than a fortieth of the strongest lamp, which keeps a night side from being black, and a glow fades out between 900 and 650 K, below which no eye sees it. A brown dwarf of 1000 K 500 AU from its star glows 17 times brighter than it reflects, so its glow is drawn at 0.44 and the light of the star on it at 0.19, and a giant close to its star, which reflects three thousand times more than it glows, is lit at 1.35 and glows at 0.12. The share of gas follows from the mass alone, none below three Earths and nearly all above 300. The hard light of the star then takes a part of it: a tenth of the energy that falls on the body over its life, set against the depth of its pull. A thin wrap of gas on a small body near its star is gone, and a giant keeps nearly all of its own. With this measure a wrap of 40 bar on a body of three Earths lasts beyond 2 AU from a Sun, as a published model finds. Beyond the frost line a third to two thirds of the rest is ice, and inside it water is a trace.
- The radius follows from the mass and the shares: rock and iron and ice by their densities, squeezed more the heavier the body, and gas by a curve that flattens near the size of Jupiter. Gas hotter than 1000 K swells, a Jupiter by a quarter at 1500 K and by half at 2000 K, a lighter body more and a heavier one less. A solid body under 3·10^20 kg is loose, with up to four tenths of it holes.
- A solid body is round when its radius is above about 360 km in rock and 240 km in ice, wholly a lump under 150 km in rock and 100 km in ice, and in between by a share. A body whose rock is molten is round at any size. For fourteen bodies of the Solar System, given the makeup usually assumed for them, it is within 5 percent, and 10 for Neptune.
- A solid body starts with a stock of eight gases: what its rock gave off, mostly carbon dioxide inside the frost line and nitrogen with some methane beyond it, its water, and what is left of the gas it formed in. A gas is gone when the escape speed of the body is less than about five times the speed of that gas on the day side, so hydrogen stays only on heavy cold bodies, and whether a body kept any air at all is drawn.
- No more of a gas stays in the air than its vapor pressure allows, taken at the cold pole where the air is thin, so carbon dioxide frosts out on a cold desert and nitrogen on a far ice body. Water vapor follows the temperature while there is a sea, and a warm body without a sea has lost its water. A sea binds carbon dioxide down to a trace, and where that would freeze the sea it keeps just enough to stay at 278 K. Only life makes oxygen.
- Pressure is the sum of what stays. Temperature is that of balance with the light of the star, raised by the gases that hold heat, each by a power of its own pressure. The gases hold less of it the hotter the body already is, a fifth at 2000 K, and never lift the ground above the temperature of the star. The two are found together by repeating the step forty times. Given the stock of each, this gives 286 K and 1.00 bar for the Earth, 800 K for Venus, 232 K for Mars and 94 K with 12 percent methane for Titan. Pluto and Triton come out airless, though they have a trace. Hydrogen is set so that 40 bar of it keep water liquid 10 AU from a Sun, as the same model finds, and hundreds of bar of it near a star leave the ground above 1000 K, with all the water of the body in the air as steam.
- A body has a sea when water is left after what stands in the air as vapor, it has air, and its temperature is between freezing and boiling at that pressure and below 647 K, above which water is no liquid at any pressure. Its sea level is then found on its relief.
- The upper air of a body wrapped in gas is hydrogen and helium with methane, ammonia and water, more of them the lighter the body, each capped by its vapor pressure at the temperature of the cloud tops. The gas that is capped is the one its clouds are made of.
- A giant has two to five moons, a lighter body wrapped in gas up to three and a solid body seldom one, between the distance at which the planet would tear a moon apart and three tenths of the distance at which the star would take it, counted for the farthest point of the moon. The moons of one body keep five Hill radii of the two together between them: the outer one is moved outward for it, and is not made where that leaves the hold. A second heavy moon is therefore found only where the hold of its planet is wide. The home body always has a moon. A moon turns one face to its planet.
- A body wrapped in gas also has up to two small moons inside its large ones, and one solid body in ten has one or two, from 1.9 of its radii outward and outside its ring. They have 10^17 to 10^20 kg around a body in gas and 2·10^15 to 3·10^18 kg around a solid one, so most are lumps. A small moon that would come within five Hill radii of the one before it is not made.
- Rock is taken to melt at 1400 K. On a body with no air the point under the star is hotter than the mean by the square root of two, so lava appears there from a mean of 990 K and covers up to the whole day side. Under thick air the heat is even, and the whole body is molten above 1400 K.
- A moon is made as a planet is, so it may be born with a moon of its own, inside a third of its own reach and outside three of its radii. That leaves room only around a large moon far from its planet, one such moon in fifty has one, and tides take it within a few million years, so it is hardly ever met. A system has 17 or 18 bodies on average and seldom more than 45.
- A moon is laid where it was born and read where tides have brought it. Its distance to the power 6.5 changes evenly with time, by 19.5 times the yield of the planet, the mass of the moon over that of the planet, the fifth power of the radius of the planet and the root of G times the two masses: outward where the moon circles slower than the planet turns and inward where it circles faster. The yield, the Love number over the quality factor, is 10^-6 for a body wrapped in gas. For a solid body it is a hundredth of 1.5 over one plus 19 times its stiffness over twice its density, its gravity and its radius, with a Love number of at most 0.4 and a stiffness of 5·10^10 Pa for rock and 4·10^9 for ice: 0.004 for the Earth, 0.0014 for Mars and 0.0003 for the Moon. By this count Phobos has 45 million years left, and a moon of 10^20 kg at two radii of Jupiter 3.6 billion.
- The heaviest moon of a planet turns it. The two keep their angular momentum between them, with the planet counted as a ball of 0.33 of its mass times its radius squared, or 0.25 in gas, and turning no faster than eight tenths of the rate that would break it. Where that moon is pushed outward the day drawn for the planet is its day in its prime, and it turned faster before. Where the moon is drawn in, the day drawn is the day at birth, and the planet turns faster as the moon comes down. A moon that reaches the orbit on which it circles as fast as the planet turns stays there, and the day of the planet is then the month of the moon, on the conventional scale as well. A lighter moon is moved against the day drawn and does not change it.
- A planet held by its star turns too slowly for any moon, so from the age at which it is held all its moons are drawn in, and a moon of a moon is drawn in from the start. A moon is torn at 1.44 radii of the planet times the cube root of the density of the planet over its own, and reaches the planet whole where that is under 1.02 radii. It is no longer listed from then on.
- The moons of a planet keep their order. Between two neighbors stays the ratio of distances they were born with or, if that is less, the larger of 1.59, where one circles twice while the other circles once, and the ratio that keeps five Hill radii between them. The heavier moon holds its course and the lighter gives way: a moon pushed inside its tearing distance is gone, one pushed past three tenths of the hold of the planet is lost, and a moon does not fall while a heavier one inside it still stands. The two moons at the rim of a ring are not moved.
- A moon that tides carry across the Laplace radius takes the plane of the side it is on, and around a planet lying on its side no moon is pushed past that radius.
- Over 1200 made systems, half of them with a home, tides leave 11 percent fewer moons: one moon in ten circles faster than its planet turns, where two in ten did, the planets held by their star keep 177 moons of 899, and 23 planets of 8700 turn with a moon.
- A disk of small matter is an inner and an outer edge, a mass, a density, a share of ice, the size of its grains, its height at its middle, the power by which that height changes with the distance and the distance beyond which its dust thins out, and a body has a list of them. A ring also carries the time since it was last fed and the time in which it wears away. A body that circles another has at most one, its ring, made of grains of a meter, inside both the distance at which the body would tear a moon apart and a third of the reach inside which it holds anything against the pull of what it circles. A moon close to its planet, and a moon of a moon, therefore have no room for one, and no ring lasts where a black body is hotter than 1200 K. A star has belts: an orbit of the ladder that no planet took becomes a belt six times in ten, and one more may lie beyond the last planet. A belt holds a few hundred-thousandths to a few thousandths of an Earth in rock inside the frost line and up to a third of an Earth in ice beyond it, and its density, which follows from its mass and its age, is under a ten-thousandth once it is a hundred million years old and under two hundred-thousandths around a home. Four systems in five have a belt and one in a hundred has four.
- The orbit of a body has a stretch, kept with its physics, and a plane, a turn of that plane about the pole of the system and a direction of its nearest point, kept with the body. The place of a body follows from the tick by the equation of Kepler, solved in five steps of Newton, on the drawn scale or on the real one, and the client draws the track of an orbit from the same function. The axis of a body has a tilt and a direction of its own. These angles and the stretches come from a third stream of random numbers, so adding them left most bodies of a seed what they were.
- A ring is read from the breaks that fed it. Forty-five bodies wrapped in gas in a hundred and five solid ones are drawn a ring: its edges, its share of ice and the density a break gives it, 0.2 to 0.95. Such a body has a break at times drawn a billion years apart on average, from a stream of its own seeded by its vigor, and every break adds a ring of that density. A moon torn by tides adds a ring of its own mass, around a body with no ring drawn too, with edges drawn from that stream, and a moon that reaches its planet whole adds none. Matter of a ring is left by one over the root of (1 + w/s)·e^(2t/w) − w/s after a time t, where w is the time in which the ring wears away, drawn for the body between 100 million and a billion years, and s is the time in which it spreads, 0.0425 turns of its outer edge over the square of its mass in masses of the body. A heavy ring so falls with the root of the time to the same mass whatever it began with, 10^20 kg around a Saturn after a billion years, and a light one only wears away. A ring is listed down to a density of 0.002.
- A ring that would spread sooner than it wears away gathers a moon of a fifth of its mass once it has spread, at the fluid Roche distance for 2000 kg/m³ or just outside the ring where that is farther. Inside the orbit on which a moon circles as the planet turns, the ring pushes the moon out to 1.59 of that distance, where it circles once while the edge circles twice, and no farther than nine tenths of that orbit. Tides then bring it down, it is torn, and its matter is the next ring, for at most sixteen turns. Outside that orbit the moon stays and tides push it outward. A planet has one such moon at a time, the one of its heaviest ring, made from a stream of its own so that no other body changes, and has none where another moon stands within five Hill radii or where the moon would stand past three tenths of the hold of the planet. Around Mars a ring of a hundred-thousandth of the planet is followed by lighter ones after 16, 106 and 770 million years, and the last gathers no moon. In 600 made systems about 450 planets have such a moon in their prime, most of them gathered from the ring a young giant was left.
- A planet that holds a hundredth of gas or more has a disk of its own until it is whole, made by the rule that makes the disk of a star, with the planet at its centre: from two radii of the planet to four tenths of its hold, cold enough for ice where the heat of the planet falls to 170 K, its moons as the bodies that clear lanes in it, and the growth of the planet in place of the hundred million years in which a star's disk thins. Only the pieces that hold gas are kept, each stands a tenth of its width high at most and no higher farther out, as the one disk of this kind that has been measured does, and there is no ice in it inside the frost line of the star. On the conventional scale it is laid among the moons as a belt is among planets. A body lists its ring first, and a ring is told from such a piece by the time in which it wears away, which only a ring has.
- A planet in gas with a moon born beyond three of its radii had larger moons before, which its disk dragged down. For half of them, by a draw from the stream of the planet, the last one came apart as the gas went, and the planet has a ring of a millionth to a hundred-thousandth of its mass from the day it is whole. It spreads, gathers a moon and wears away as any ring does.
- Over 1200 made systems 45 bodies in gas in a hundred have a ring in their prime, 22 a dense one of 0.2 or more, 15 a thin one and 8 one under 0.02, where 45 had a dense one by the earlier draw. Of solid planets 9 in a hundred have a ring, and of moons 2. Laying a system takes 3.4 ms with a home and 4.6 ms without. The two moons at the rim of a ring are there from the first break of their planet on, whether or not its ring has lasted.
- The stretch of an orbit around the star is mostly under 0.05 and at most 0.15. Six orbits in a hundred are stirred, up to 0.6, but an orbit never takes more than eight tenths of the room to the next rung of the ladder, so neighbors cannot cross. Twenty systems in a hundred with no home are scattered, as most systems with giants once were: four rungs in ten keep a planet, no belt is left, and six planets in ten are stirred. A body is given the light of its mean distance, and holds moons and a ring by its pull at the nearest point. The home is stretched by no more than 0.03.
- Neighbors on the ladder keep a gap between the farthest point of the inner one and the nearest point of the outer one of no less than six Hill radii of the two together, taken at the mean of their orbits. Jupiter and Saturn keep six and a half. Where the orbits as drawn leave less, the outer one is made rounder, and where a round orbit still falls short it is moved outward, and every rung and belt beyond it by the same share, so the ladder widens where heavy bodies need room. A pair set right this way is given eight to ten radii and not six, so no crowd stands at the limit itself, where a chain of planets would not last. The ladder widens to three times at most. A planet that may not move, inside the home, inside the room a companion star leaves or past that widening, is made lighter until it fits, and is not made where nothing would fit, as beside a giant. Of a hundred planets five or six are moved, by 1.6 times on average, five are made rounder, three or four lighter and two or three are not made, and the outermost planet lies beyond the old edge of the ladder in one system in thirteen with a home and two in seven without.
- The plane of an orbit around the star is mostly within 5 degrees of the plane of the system, and five in a hundred lie between 9 and 46 degrees. A moon has a stretch under 0.02 and circles in the plane of the equator of its planet while it is inside the Laplace radius of the planet, where the bulge of the planet outweighs the star, and in the plane of the orbit of the planet beyond it. That radius is the fifth root of the bulge, with the moons nearer in counted as rings, times the cube of the orbit of the planet and its mass over that of the star: 8 radii for an Earth and 27 for a Jupiter. Four large moons in ten lie beyond it, the moon of the home among them, as the Moon does. A planet held to its star has next to no bulge, and its equator is the plane of its orbit anyway. One planet in twenty-two turns freely with its axis leaning more than 50 degrees, and has no moon beyond that radius, as Uranus has none: an orbit just outside it, pulled one way by the bulge and another by the star, does not last.
- Three in ten of the small moons of a solid body were caught, with a stretch up to 0.2. Inside the Laplace radius their plane is any, backward as often as not. Beyond it they lean no more than 39 degrees from the orbit of the planet, forward or backward, because the star stretches a steeper orbit until the moon falls, which is why no far moon of the giant planets circles between 55 and 130 degrees.
- A moon always turns one face to its planet. A planet is held the same way when it is nearer its star than half an AU times the cube root of the mass of the star in Suns and the sixth root of the age over ten billion years, and a body of ten Earths or more at three tenths of that. A body so held has its day equal to its year, its axis upright on its orbit and a tenth of the stretch it would have had. About one planet in four is held, among them every world of a brown dwarf. The home is not, whatever its star, and its day is the one drawn for it.
- The temperature of a body is that of the mean light over its orbit, and with it are kept the temperatures at the nearest and the farthest point of the orbit around the star, which for a moon is the orbit of its planet. Only the light of that star changes along the way, and the body follows it as far as the heat it stores allows: by one over the root of one plus the square of 2π times its slack over the year, where the slack is the heat a square meter stores for a kelvin over the heat it sheds for a kelvin. A solid body stores heat in its air, in fifty meters of sea where it has one, and in the ground as deep as the wave of a year reaches, and a body in gas in its uppermost bar. On an orbit stretched by 0.5, bare rock of 280 K runs from 222 to 379 K, a sea world of 288 K from 273 to 313 K, and a giant far from its star hardly moves. The core gives the temperature at a tick from these and the place on the orbit. Air and sea themselves are still worked out for the mean alone.
- What the temperature leaves out was measured over 3000 made systems, half of them with a home, with the same reckoning of stored heat. The light of the other star and of a glowing host enters the temperature as a mean and does not swing. With a far second star that loses at most 0.9 K, since the other star gives no body more than 6 percent of its light. In a close pair the two stars circle the point between them, and the light on the innermost planets, at four to six of their distances, beats by up to a fifth either way with their period, half a day to two months. A bare world there would swing by up to 32 K, 37 bodies in 1751 by 5 K or more, and a home by no more than 0.3 K. They are barren and desert worlds, none molten and none with a sea, so the numbers would change and the picture hardly. A moon on an oval orbit close to a glowing host would swing by up to 54 K, 22 moons by 5 K or more, but tides would have rounded such an orbit long ago, and it is the orbit that should change. An eclipse of one star by the other is not counted, and a body does not lag behind its light.
- The beat of a close pair can be added to the temperature at a tick without a change to what is stored with a body: the light of the two stars where they stand at that tick, against their light as from the point between them, followed as far as the heat the body stores over the period of the pair allows. It waits until a rule reads temperature.
- Physics is in SI units and is rounded to five significant digits when the system is made.
- The conventional scale is worked out once and stored with the body. A radius is the real one, relative to the home body, raised to the power 0.45, so a star is about eight times and a giant about three times as wide as the home. An orbit around a star, the second one too, is the real one, relative to that of the home, raised to the power 0.37, and the orbit of a moon grows with the square root of the real one. An orbit is then moved outward as far as needed for its nearest point to clear the farthest point of the body inside it with its ring and moons, and the nearest one stands at least 1.7 radii of the star from its middle. Where a body is wider than the one it circles, as a star beside a heavier white dwarf or black hole or a giant planet of a white dwarf, that room is counted from the wider of the two, so the wider passes no nearer than 1.7 of its own radii, and the next orbit outward keeps as far from it. A period is the real one, relative to that of the home, raised to the power 0.6. A system with no home is measured against an Earth standing where the light of its star is that of the Sun on the Earth. A belt takes its place among the orbits by the same rule, between its neighbors, and a body carries the drawn edges and the period of each of its disks.

## Flight

- The page `flight.html` needs no server. It takes the survey of a seed, sets a ship into a low round orbit of the home, or of the first planet of any star where there is none, and flies it in the browser with the functions of the core.
- The core keeps a second way to the places of bodies, the rails: the same walk down the tree as for a sketch, with the two axes of every orbit worked out once and the results written into arrays of numbers. It gives the speed of every body as well, by the rule of the orbit and the rates at which a shared orbit sways and widens, not by differences. A test holds the rails to the places of the sketch within a ten-billionth and their speeds to differences of places.
- The ship is flown by the embedded pair of Fehlberg of orders 7 and 8. Its thirteen stages fall on ten moments, and the places of the bodies are worked out once for a moment and kept, the last of a step serving as the first of the next. A step is kept when the two orders agree within a ten-billionth of the distance to the body that pulls hardest and of the speed of a round orbit there. A round orbit takes about 35 steps a turn, and after 200 turns of a low orbit long steps and short ones end 50 to 75 m apart.
- Two more limits bind a step, because that estimate sees neither. A step is no longer than a quarter of the distance to any body over the speed relative to it, so that no body is stepped over. While the engine burns, a step spends no more than a twentieth of the mass of the ship: the estimate is blind to a push that depends on time alone, and without the limit a burn in empty space was off by a twentieth of a meter a second in five kilometers a second.
- A burn against the path would drive the relative speed to nothing and then flip its heading with every step. Below a few meters a second its thrust and its use of propellant fall with the speed, so the ship settles where the thrust left balances the pull, and the step stays about a tenth of a second.
- A body holds a ship inside its domain: the nearest point of its orbit times the mass ratio to the power 0.4, over one plus that power, which is the usual sphere of influence for a light body and half the distance for two alike. The body whose domain is smallest among those the ship is in gives the readings and the headings.
- The places of 17 to 35 bodies take 13 to 34 microseconds and a step 130 to 330, so one thread flies 3000 to 7700 steps a second. The page gives the flight 7 ms of every frame, which is 15 to 50 turns of a low orbit a second, and shows the speed reached beside the speed of time asked for when that is more.
- The scene takes the ship as a point to follow that is no body, and draws what is near the eye in a second pass with a depth of its own: the ship, a few meters across, 30 m from the eye and before a planet 300 km away. The ship is lit by the star brightest where it flies and is dark in the shadow of a body, and it is not drawn where a body hides it. Farther than its width of a few pixels it is a name on the screen.
- A forecast is a copy of the flight flown ahead with the engine off. It keeps a sample for every step: the time, the place and speed of the ship, the places of all bodies and the body holding the ship. A step of a forecast is no longer than 0.09 of the distance to that body over the speed relative to it, about five degrees of a round orbit, so the samples can be joined by straight lines. With no span asked for it ends 1.1 turns after the last planned push where the orbit is closed and stays inside the hold of its body, and otherwise after three times the way out of that hold at the speed of the moment, and it reckons that end anew whenever the hold changes, up to four times. A turn of a low orbit is 81 samples and 16 ms, and a way out past a moon into an orbit of the star 160 to 200 samples and 85 ms.
- A planned push that names its engine is flown by the forecast as the ship will fly it. Half the length of the burn before the moment of the push the forecast flies a copy of the ship on to that moment, finds the axes of the push from its place and speed there, and then burns along that direction, held against the stars, for the time the rocket equation gives. The page burns the same way, so the path drawn is the path flown: a push of 800 m/s given all at once promised a highest point of 4142 km, the engine gave 4136 over two and a half minutes, and the forecast now says 4136. A push that names no engine is still given at once.
- The page gives a forecast 3 ms of a frame and shows the last one finished. It starts another when the plan or the settings of the path change, when the engine has burned, and when the ship has flown a quarter of the span shown. A new forecast takes over the arrays of a spent one: 5000 samples with the places of 35 bodies are 4 MB.
- The path is drawn as separate segments, one set for each body it is drawn around, stored as offsets from the first point of the set and moved with that body every frame. Where the path is drawn turning with a body, the points are stored in axes that turn with it, along the line from what it circles and along the pole of its orbit, and the set is turned by where those axes stand now. The part already flown is not drawn, and the first point drawn is moved to the ship.
- The marks on the path are plain HTML placed every frame: pushes, the first lowest and highest point after the last push, the nearest pass by the target, the place where the path meets the ground and the points of balance. Lowest, highest and nearest points are found among the samples and set between them by a parabola through three. A mark behind a body is not shown.
- The instruments are plain HTML over a scene that fills the window. The projection of the camera is shifted down by a ninth of the height, so the body or ship looked at stands above the instruments at the bottom.
- The ship keeps the direction of its roof beside that of its nose. When a heading turns the nose, the roof is made square to it again and nothing more, which is the turn with the least twist: a ship following its path keeps its roof to the sky.
- The ball is drawn on a canvas 144 pixels across. Every pixel is a direction as seen along the nose, colored by its height over the horizon, and the rings and spokes are found by products of vectors with no trigonometry, in about a millisecond. It is drawn again only when the attitude has changed by a fortieth of a degree. The marks lie on a second canvas at the density of the screen and share their outlines with the heading buttons.
- A click on the scene is offered to the page before the scene looks for a body under it. The page takes the click when the path runs within 12 pixels of it, or 26 for a finger, at a point no body hides, and offers a push or a run of time there.
- While a part of the plan is being changed, the forecast under way is finished and shown before the next one starts, and forecasts get 9 ms of a frame in place of 3, so the path follows the change.
- The numbers of a push were first set by sliders that sprang back and set the speed of change. The reach wanted differs a thousandfold between a push in a low orbit and one aimed at a far body, so the right pull had to be hunted for each time, and an overshoot hunted back. Each digit now takes its own notches, which picks the scale by pointing and makes every change exact and reversible. The lever beside them sets the size and not its speed of change: its place maps to the part through a power of ten, six decades to a side or a thousand kilometers a second, and the result is rounded to two figures. Four and a half decades fell short of pushes between the stars of a close pair.
- A push dragged along the path needs the path it would lie on without itself: when the drag starts, one more forecast is flown with only the pushes before it, drawn faintly, and the mark goes to the point of it nearest the pointer on the screen, between the pushes before and after.
- Time run to a point takes, every frame, the fastest speed that would not arrive within a second, and no more than ten times while the engine burns.
- A ship that met the ground is set on the surface, at rest with the body. The step that found it may have ended kilometers below.
- The flight asks for the ground only under the ceiling of a body, its radius and the most its relief and rims can add, so an orbit costs what it did. Under it a step ends on the ground where the ship is below the height there and the 5.2 m it stands on. Its speed against the turning ground then decides between a landing and a loss. A landed ship is not flown: its place turns with the body until the engine lifts it.
- The core gives the ground of a patch as a function made once. Craters wider than half the patch are gathered into a list, and only the finer layers are searched at each point. It agrees with the plain function within 10⁻¹² m and costs 14 to 26 µs a point, most of it noise.
- The ground of a round solid body is drawn as tiles once the eye is within half a radius of it: a tree of quarters on the six faces of a cube, with equal angles along a face, each tile 32 cells a side with a skirt around it. A tile is split while the eye is nearer than 1.4 of its edges, down to the level where a cell is between half a meter and a meter, 17 levels on a moon of 1500 km. A tile takes the ground at a grain of three tenths of its cell, so neighbors of two levels differ only by craters a cell cannot show, and the flight takes it at the grain of the finest tiles. Tiles beyond the horizon are neither split nor drawn, a tile is drawn in place of its quarters until all are made, and the six coarsest are made before the globe is hidden. Heights come from the core in up to four workers, 17 to 33 ms a tile, so no frame waits for one: the page lists the tiles it lacks, coarsest and nearest first, and a worker that has finished takes the next at once. Some 850 tiles stand around an eye on the ground, and 1000 are kept.
- A tile is a mesh of its own, placed at its middle and holding offsets from it, so a vertex a meter from the eye is exact on a body thousands of kilometers wide. It is colored by the shader of the body from the same map, so the ground has the colors the globe had, and lit by its own normals. The slopes of the map are added only to tiles coarser than the map, and clouds fade below 60 km. A finer tile varies its color by a grain of three sizes, 8 m, 1 m and 25 cm, read at a place in meters that repeats every 256 m and is counted per tile so that neighbors agree.
- The nearest plane of the view follows the height of the eye over the ground, down to 0.2 m, and the eye is kept 1.5 m above the ground. Within a twentieth of a radius the scene is turned so that up on the screen is up at the ship, and beyond three tenths it is not turned at all.
- The rover is a point on the ground with a heading and a speed, stepped twenty times a second of its own time: its engine, the pull along the slope under its wheelbase, rolling drag and a grip of 0.8. Heights at five points give its slope and its tilt. It runs no faster than four times real time, and stands braked while the ship is in hand.
- A way to another body is sought in the core by a search that hands control back after every forecast, and the page gives it 6 ms of a frame. It starts from ways between two places in a given time around one mass, found in universal variables with the root halved in, and tried over the moments of leaving and 24 lengths of flight. For a body that circles what the ship circles the way starts at the ship's own place on its coast. For a body beside the one the ship circles it starts at that body's place, and is turned into a burn along the path at the point of the parking orbit from which the ship leaves the hold in the direction wanted; the cheapest moment within a round of the two bodies is reported when it beats leaving now by a tenth.
- Such a start misses by thousands to millions of kilometers, and is corrected against the real forecast. The pass is measured as the lever arm of the miss in the plane square to the approach: inside the hold of the target off the hyperbola about it, which stays defined where the path meets the ground, and outside off the nearest point, found between samples by a cubic. The three parts of the push are moved by the smallest change that the slopes say brings the lever to the length the wanted height asks. The slopes are measured by three nudged forecasts, kept up by Broyden's rule, and measured anew when a step cut to a third three times over still does not help.
- A way to the moon of the home takes about 55 forecasts and 0.75 s, to the next planet 35 forecasts and 0.7 s, starting 16 million km off. A burn of 12 km/s, 41 minutes with the standard engine in an orbit of 92, is not found: the start assumes a burn short against the turn.
- The throttle is on R and F. With Control held for it, as other games have it, turning with W would close the tab.
- The three points of balance on the line of two bodies are the roots of their quintics, found by halving, and the other two stand at sixty degrees. A test finds the point between a home and its star by flying ships from both sides of it until neither falls either way, and gets the place the quintic gives within half a percent.
- The first frame of a page can come with a time before the scene was made. The scene takes such a span as nothing, where it once shrank the camera to a point.

## Stability

- Beside the rails the core keeps an integrator in which every body pulls on every other. It works in the coordinates of the tree the rails use: an orbit is the path of a body, with all that circles it, about the middle of the mass of its parent and of the nearer children. A step is a round of every such orbit by the rule of two bodies and one push by everything those orbits leave out, which is the mapping of Wisdom and Holman carried to a tree, as Beust did. The rails are those orbits, so a run starts from the rails at time zero and gets the orbits of the generator back within a thousandth.
- The pull between two bodies is worked out from places counted from their nearest common parent, so a moon far from the middle of a wide system loses no digits. A body pushes its children as a flattened one, by the bulge that follows from its day: the outward pull of its spin over its own pull at the equator, times a third of 0.4 for a body in gas, of 0.93 for a solid one and of 0.03 for a star. Without the bulge the star would tear a moon out of the equator of a planet lying on its side, which it does not do in nature.
- A step is a twentieth of the quickest turn, counted at its nearest point, so no single run follows both a moon of half a day and a star of a hundred thousand years. Runs are stacked in a ladder. A run takes the bodies whose years are no shorter than its cut and counts the quicker ones into their parents, as mass and as a ring that flattens the parent further, and each cut is eight times the last. Asked for a number of turns of the cut, the ladder follows every body for an eighth of that number to all of it, beside everything slower than the body.
- A run ends at the first mishap: two neighbors nearer than one Hill radius of the two together, two bodies touching, an orbit left open, or an orbit so stretched that a step cut six times no longer follows its nearest point. The lighter body is then taken out and the run made again, up to four times, so one system can show several losses. A body taken out is absent, and those left keep the shapes of their orbits.
- A loss is given a cause by what the two bodies are and by four numbers of the body: the gap to its nearest neighbor in Hill radii, the share of the hold of its host that it uses, the angle between its orbit and that of its host, and its distance over the Laplace radius of the host, inside which the bulge of the host holds an orbit to the equator.
- Five bodies take 0.9 microseconds a step and 28 take about 8. A system of 20 bodies costs about 4 s for ten thousand turns and 85 s for a hundred thousand. Tests hold the integrator to four giant planets that keep their energy within a hundred-thousandth over thirty thousand years, to two planets that meet at 2.8 Hill radii apart and keep away at 4.2, and to a planet on its side whose bulge holds a near moon and not a far one. With a step three times finer, 39 losses of 47 fell on the same body, and 59 systems run anew showed 18 with a loss where the coarse step showed 14: the moment of a loss is chaotic and the count is not.
- `pnpm stability` runs the ladder for a series of seeds on every processor and prints, for systems with a home and without, the share that lose a body and the causes. `--list` names every loss.
- Before the generator kept the gaps, holds and planes written under Bodies, 23 systems in a hundred with a home and 27 without lost a body while each was followed for 1250 to 10 000 turns, 2 bodies in a hundred, and 37 systems in a hundred over ten times as long. The causes were planets nearer than about five Hill radii and those they stirred, moons in the equator of a tilted planet beyond its Laplace radius, moons sharing the orbit of a far moon, two heavy moons of one planet and moons beyond three tenths of the hold. No star and no planet inside the room a companion star leaves it was lost. Those rules came of that series and were tried first by taking the offenders out of the old systems.
- With those rules 6 systems of 400 with a home and 5 of 400 without lose a body over the same turns, where 84 and 100 of the same seeds did before, and none loses its home. What is left are planets steeper than 39 degrees to the orbit of a companion star, which that star stirs in time, small planets in a resonance with a giant, planets near the limit a companion sets, and now and then a body that shares an orbit. Run again once stars had lives, and again once a system was laid at birth and read at an age, the series gave the same counts, and no system among them around a giant, a white dwarf, a neutron star or a black hole lost a body. Without the rule that lets the lighter of two crowded planets go, two systems around white dwarfs lost a planet to its neighbor. With systems met young among them the counts stayed the same, once bodies that share an orbit were held back until a system is grown: before that one young system lost two such moons of a giant still wide with its own heat.
- Two tests hold the generator to the rules. One reads the gaps, the holds and the planes of 120 made systems, and one follows six systems for three hundred turns with every body pulling on every other. They take about four seconds between them and run beside the longer tests of the world, so a check takes no longer for them. The series is left to the command, which takes six to eight minutes for 400 seeds of each kind on eight processors.
- Tides, relativity and the turning of a spin axis are left out. Tides would take the moons of a planet held to its star, which the integrator keeps.

## Cell level

- A map is made from 400 points on the sphere. The 248 where the relief of the home body is highest become land cells, and the highest 45 of those are mountains. The sea level and the mountain level found this way are written into the description of the body. Cells are joined into regions by growing them outward from seeds at uneven speeds, with mountains slowing the growth so that ranges tend to become borders.
- Neighbors come from the hull of the land points, built point by point: 6 ms for 400 points and 15 ms for 800. Testing every triple of points took 46 s for 680. Two neighbors are joined by land when the side their Voronoi cells share has a dry point within reach of them, sampled every hundredth of a radian. The shortest of the other pairs become straits until all land is connected. Making a world with its star system takes about 16 ms.
- With 250 cells a tick takes 1.0 ms and the three bots another 0.2 ms. At the top speed of 16 ticks a second this is about 2% of one processor core. A save is about 250 KB.
- Almost half of a tick goes into finding the way that loses least: once for matter, twice for force, once for every round of energy and once for every road order.
- A series of 12 bot matches of 6000 ticks takes about 90 s on one thread. The match runner accepts changed constants, so a tuning idea can be tried on a whole series.
- A full view every tick stays affordable, but the compact or delta encoding listed under Deferred comes closer as maps grow.

Deposits and stocks are stored by kind from the start, with a single kind until matter is split in stage 4. Once kinds multiply, only the dear ones should be carried from cell to cell and the rest counted as totals per power: by estimate, thirty kinds carried in full would make a tick about ten times slower.
